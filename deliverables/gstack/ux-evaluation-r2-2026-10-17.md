## 1. 用户旅程（文字版）

### 场景 1：搜索城市 → 生成攻略 → 导出海报

```
打开首页(716ms) → 输入「成都」(527ms，联想在 160ms 防抖后出现)
  → 回车，加载层 26ms 内出现 → 等待 12,959ms → 结果页渲染
  → 浏览 23 个内容区块（总高 7980px）
  → 点击导出海报 → 3,558ms 后完成（首次需动态加载 html2canvas）
```

**观感**：首屏和交互响应都很快（<1s），但生成是断崖式等待——13 秒里用户只能看加载条和轮换文案。结果页内容极其丰富（预算/天气/地图/美食/住宿/比价/贴士都有），但长度接近 8 屏，没有目录。

### 场景 2：收藏 → 比价 → 查看地图

```
在结果页点收藏(541ms 完成) → 比价区渲染 11 张平台卡片
  → 地图容器存在，但显示「高德地图脚本加载失败」
```

**观感**：比价信息密度高、实用（11 个平台）。收藏动作本身无即时可见反馈，需要打开收藏列表才能确认。地图是本场景的预期亮点，但当前环境不可用。

### 场景 3：天气信息 → 离线降级

```
结果页天气卡显示「20°C 实时天气：阴，湿度 88%，北风 1级，能见度 16公里」（真实数据）
  → 打开 offline.html(546ms) → 「当前处于离线状态…重新连接 / 历史攻略 / 本地照片」
```

**观感**：天气是真实数据，不是占位。离线页文案清晰，明确告诉用户「已生成的内容仍可访问」，这比常见的「网络错误」友好得多。

## 5. 地图不可用的根因（重要，避免误判）

实测高德脚本请求返回：

```
HTTP/1.1 200 OK
Content-Type: application/json
{"info":"INVALID_USER_DOMAIN","infocode":"10006","status":"0", ...}
```

- **根因**：该 Key 在高德控制台配置了域名白名单，`127.0.0.1` 不在其中
- **表现**：高德返回 JSON 而非 JS → 浏览器 **ORB（Opaque Response Blocking）** 拦截 → `window.AMap` 未定义
- **代码侧评价**：降级逻辑是**正确的**——地图区域显示「加载失败」而非白屏或报错中断，攻略其余内容正常渲染
- **结论**：这是**部署配置项**，不是代码缺陷。生产环境需在高德控制台把正式域名加入白名单

> 因此本报告不把「地图不可用」计入代码问题，而是列为上线前配置检查项。

## 6. 改进建议（8 条）

| # | 问题 | 改进方案 | 预期效果 | 实现难度 | 优先级 |
|---|---|---|---|---|---|
| 1 | 生成等 13s 无进度 | 后端改 SSE 流式返回，前端按「行程→美食→住宿→预算」分段渲染，先出骨架再填充 | 首屏内容可见时间从 13s 降到 2–3s，感知等待大幅缩短 | 高（后端改造） | **P0** |
| 2 | 结果页 8 屏无导航 | 顶部加粘性目录条（行程/美食/住宿/预算/比价/贴士），滚动高亮当前区块 | 定位成本从「滚 8 屏」降到「点一下」 | 低 | **P1** |
| 3 | 海报导出 3.5s 无反馈 | 按钮进入 loading 态 + 进度文案（加载组件/渲染画布/生成图片） | 消除「点了没反应」的疑虑 | 低 | P1 |
| 4 | 收藏无即时反馈 | 收藏后 toast 带「查看收藏」action 按钮（`toast` 已支持 action，可直接复用） | 操作闭环可感知 | 极低 | P1 |
| 5 | 地图失败无指引 | 失败态文案改为「地图服务未配置，攻略其他内容不受影响」，并在管理端提示配置域名白名单 | 用户不再困惑，运维有据可查 | 低 | P2 |
| 6 | 加载文案是固定值 | 改为按已耗时动态显示（如「已用时 8 秒，通常需要 10–20 秒」） | 减少「说 10-20 秒却等 30 秒」的失信感 | 极低 | P2 |
| 7 | 长页一次性渲染 | 结果页 section 分批渲染（先首屏 3 个区块，其余 IntersectionObserver 懒渲染） | 首次渲染长任务从 150ms 降低 | 中 | P2 |
| 8 | 离线页无缓存入口 | 增加「查看已保存攻略」按钮，直达本地历史列表 | 离线价值可兑现 | 低 | P3 |

## 7. 新功能建议（4 条）与初步 Roadmap

| # | 功能 | 用户价值 | 实现难度 | 优先级 |
|---|---|---|---|---|
| N1 | **行程分享链接** | 生成后可一键生成只读分享页，免登录查看。旅行场景天然需要「发给同行的人」，这是最高频的社交需求 | 中（需短链 + 只读渲染 + 过期策略） | **P1** |
| N2 | **多城市对比** | 同一次出行常在城市间犹豫（如成都 vs 重庆），并排对比预算/天数/季节 | 中 | P2 |
| N3 | **离线预下载** | 出行前把攻略+地图瓦片缓存到本地，无网也能看（当前离线页只能看已生成的） | 中高（地图瓦片缓存受高德条款限制） | P2 |
| N4 | **行程日历导出** | 导出 .ics 到系统日历，按天提醒 | 低 | P3 |

### Roadmap（按依赖关系排，不含日期）

```
第一阶段（体验止血）
  ├─ 结果页目录导航（改2）
  ├─ 海报进度反馈（改3）
  ├─ 收藏 toast action（改4）
  └─ 加载文案动态化（改6）

第二阶段（性能攻坚）
  ├─ AI 流式输出 + 分段渲染（改1）   ← 依赖后端改造，收益最大
  └─ 结果页分批渲染（改7）

第三阶段（价值扩展）
  ├─ 行程分享链接（N1）
  ├─ 多城市对比（N2）
  └─ 离线预下载（N3，需先确认高德条款）
```
