## 2. R1 → R4 改动脉络（各轮均有独立验证背书）

- **R1（v11.0）「东方编辑体 · 精修升级」**：中文精排（palt / text-spacing-trim / em 定宽 / 孤字修复）、纸感底纹、落款印章、墨迹落定动效、微交互、响应式收口；修复 P0（375 结果页横向溢出 273px → 0）、P1（Hero 孤字）、P2（768 工具条挤压）。
- **R2（v11.1）反馈修复 + 立轴首现**：触摸目标 7/32 → **0/0**（fine + coarse 双口径）；无障碍 6 处缺口全修（skip-link / footer landmark / 弹层 dialog 语义 / 导航语义 / 焦点环 ×2 / 控件标注）；徽章色彩收敛；**原创水墨立轴 SVG 装置（桌面）**。
- **R3（复验轮）**：QA + 调查员独立复验 R2 —— 🟢 通过；60fps 达标；2 项 Level A 缺口（listbox / 标题层级，需 app.js）记录在案。
- **R4（v11.2）终轮**：
  - **行程线「绘出」动画** —— `pathLength=1` + `stroke-dashoffset 1→0`（1.6s，延迟 1.15s，expo-out 型缓动 `cubic-bezier(.16,1,.3,1)`），节点 1.7s / 登顶 2.35s 错峰点亮；
  - **立轴跨端化** —— ≤860px 由 `display:none` 改为可见、`order:2` 置于搜索卡之后、水平居中、宽 `min(48vw,190px)`；
  - **结果页母题延伸** —— `.gc-head::after` 远山 / 等高线（mask + opacity .07 + z-index -1）；
  - **reduced-motion 全面降级** —— 整组动画仅挂载于 `prefers-reduced-motion: no-preference`。

## 3. R4 终审验证汇编

### 3.1 质量门神（QA）要点 —— 详见 `verify-r4/VERIFY-R4-REPORT.md`
- 六档横向溢出：**全 0**（1920 / 1440 / 1024 / **768 / 414 / 375**，首页 + 结果页；含本轮改动过的三档）。
- 触摸目标：**0 欠尺寸**（fine + coarse 双口径，全量选择器）。
- 功能回归：**17/17 PASS**；控制台与基线一致（2 条为后端缺失的预期回退），`pageerror` 0。
- 跨端签名实测：≤860px 立轴**可见、居中、位于搜索卡之后**（aside.y ≥ card.bottom）、**不挤压主 CTA**；≥861px 桌面布局未改动。
- 墨迹动画在 reduce 下**正确禁用、静态全显**。

### 3.2 调查员（性能 / 无障碍）要点 —— 详见 `perf-a11y/r4/REPORT-R4.md`
- 绘出动画帧成本（窗口对齐 4+4）：绘出窗口 **8/8 组全覆盖**；窗口内 >33ms 缺口 **ON 1/4（单处 50ms，CDN 降级运行）· OFF 0/4**；挂载/首绘停顿（83–467ms）**开/关两组均 8/8 出现** → 加载固有，非动画引入。
- 纯滚动（清缓冲）：**60.0fps / 0 掉帧 / 0 长任务**（开/关一致，与 R1/R3 基线持平）。
- 768 跨端立轴：60.0fps / 0 掉帧 / 0 长任务 / 溢出 0。
- reduced-motion（1440 + 768）：动画禁用（none / 1e-05s）、立轴静态全显、路线笔画可见。
- 结果页母题：h2 对比 **16.25:1**；装饰层 opacity .07 / z-index -1 / pointer-events none / 有 mask → 不影响可读性与命中测试。
- 无障碍复测：a11y / a11y2 / a11y3 三组（冻结后重跑）**与 R3 逐字段一致 → 零回归**。
