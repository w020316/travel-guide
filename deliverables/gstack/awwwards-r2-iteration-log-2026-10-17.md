## 2. 三轮迭代记录

### 第一轮：资源链路与字体真实落地

**驱动数据**：阶段一实测 —— 页面声明 **808 个 FontFace**，单字重 92 个 unicode-range 分片，`load` 事件 **≥45s 超时**。

**关键认知**：上一轮把「Noto Serif SC 衬线展示」写进了设计系统，但字体靠 Google Fonts CDN 分发。在目标用户（中国大陆）环境下 `fonts.gstatic.com` 不可达，**这套排版设计实际是失效的**——用户看到的是系统回退字体。评分 9.0 是"设计意图"的分，不是"实际渲染"的分。

**本轮改动**：
- 用 fontTools 把 Noto Sans SC / Noto Serif SC 子集化为单文件可变字体（GB2312 一级汉字 4145 字形，wght 轴覆盖全部字重）
- 自托管到 `lib/fonts/`，`@font-face` 声明 `font-display: swap`
- html2canvas 一并本地化并按需加载

**实测**：

| 指标 | 改前 | 改后 |
|---|---|---|
| FontFace 声明 | 808 | **2** |
| 境外请求 | 112+ | **0** |
| `load` 事件 | ≥45s 超时 | **548ms** |
| h1 实际字体 | 回退到系统宋体 | **Noto Serif SC 80px/900** |
| 跨引擎命中 | — | Chromium 14/14、Firefox 14/14 |

**维度影响**：1 排版 +0.2（从"意图"变成"事实"）、7 响应式（无变化，但排除了字体导致的布局抖动）

---

### 第二轮：暗色模式（色彩系统补全）

**驱动数据**：阶段一实测 `prefers-color-scheme` 全项目 **0 处**，7 档视口 × 暗色 `darkApplied` 全为 N。

**设计推导**（不是简单反转）：
- 底色 `#17140F`（H≈37）与亮色纸 `#FAF7F2` 同一暖色轴，避免冷灰化
- 文字 `#F3EDE3` 是暖白而非纯白
- 品牌赭红按「一色两用」提亮：装饰 `#D9705A`、文本 `#E9907A`（7.64:1）

**非颜色调整**（这些才是暗色真正的难点）：
- 阴影改纯黑 + 提高透明度，层级改由 `--line-2` 描边承担
- 噪点纹理 `multiply → screen`（否则深底上完全不可见）
- Hero 网格不透明度 .2 → .42
- 海报画布固定亮色（导出 PNG 是独立视觉系统）

**实测**：
- 30 组令牌配对全部 ≥ AA
- 运行时遍历可见文本：首页 159 + 结果页 278 + 收藏弹窗 284，亮暗双套 **721 处，0 处不达标**
- 6 种「系统 × 手动」组合全部正确
- 亮色回归：12 个探针的 color/background/border/shadow 逐项一致

**维度影响**：4 色彩 +0.5（这是本轮最大单项提升）

---

### 第三轮：视觉层级与动效覆盖

**驱动数据**：阶段四实测 —— 结果页高 **7980px**（约 8 屏）、13 个区块、无任何导航；SUS 77.5 分未达标。

**本轮改动**：

| 改动 | 解决的问题 | 实测 |
|---|---|---|
| 粘性目录导航 | 8 屏长页无法定位 | 13 条目录、48px 触摸高、3 档视口零溢出、sticky top=8px |
| 结果页区块入场 | `initScrollReveal` 选择器不含 `.gc-section`，13 区块硬出现 | 13/13 挂 reveal，滚动按视口推进（1→3） |
| 提示改语义类 | 内联色值导致暗色下 2.56:1 | 删除 2 段 `!important` 补丁，无新增 |

**过程中修掉的回归**：`.guide-col` 是 grid 子项，`min-width: auto` 被目录条撑到 1203px，导致 375 视口整页溢出 848px。补 `min-width: 0` 后归零。

**维度影响**：3 层级 +0.2、5 动效 +0.2、6 微交互（保持 9.0，新增 hover/active/is-active 但整体已饱和）

## 3. 逐维度证据

### 维度 1 · 排版设计（9.2）

| 检查项 | 实测 |
|---|---|
| 字族分工 | 衬线 Noto Serif SC（展示）/ 无衬线 Noto Sans SC（正文）/ mono（数字） |
| 字号阶梯 | 11 档 UI + 4 档流体 + 3 档展示，全部令牌化 |
| 行高 | 正文 1.75 / 标题 1.12（中文方块字需更大行距） |
| 字距 | 大标题 -.015em / eyebrow .12–.3em |
| 多平台一致 | Chromium、Firefox 均命中 Noto（14/14） |
| 断行控制 | 标题 `text-wrap: balance`、正文 `pretty` |
| 字体合成 | `font-synthesis: none` 禁止伪粗体 |

**扣分点**：字重只用了 400/500/600/700/900 五档，可变字体的中间值（如 650）未利用。

### 维度 2 · 留白运用（9.0）

| 检查项 | 实测 |
|---|---|
| 栅格 | 4px 基数，18 档令牌（`--space-4` ~ `--space-96`） |
| 容器 | 1180px / ≥1440 切 1320px |
| 区块节奏 | 结果页 section 间距 44px，标题下 28px 分隔线 |
| 目录条 | padding 4px + item 内距 16px，与全局节奏一致 |

**扣分点**：结果页 8 屏长度下，区块间距恒定 44px，缺少"章节大分隔"（如每 3 区块一个 96px 呼吸位）。

### 维度 3 · 视觉层级（9.2）

| 检查项 | 实测 |
|---|---|
| 标题层级 | h1（Hero/结果页主标题）→ h2（区块）→ h3（卡片） |
| 编辑标记 | eyebrow（短横线 + 宽字距）、区块序号 `.gc-idx`、栏目覆盖线 |
| 新增 | 粘性目录：当前区块赭红实底高亮，其余灰色 |
| 视觉权重 | 品牌色只用于强调，正文用 ink/ink-2/muted 三级灰 |

**扣分点**：目录条 13 项在 1440 下需要横滚，一屏看不全（设计取舍，非缺陷）。

### 维度 4 · 色彩系统（9.5）

| 检查项 | 实测 |
|---|---|
| 亮色对比度 | 19 组全部 ≥ AA |
| 暗色对比度 | 30 组全部 ≥ AA |
| 运行时审计 | 721 处可见文本，亮暗各 0 失败 |
| 令牌化 | 0 处硬编码色值（`app.js` 仅剩 1 处数据驱动的 `dayColors` 图例色） |
| 品牌一致性 | 「一色两用」：`--accent` 装饰 / `--accent-text` 文本 |

**这是本轮最高分**：色彩从"单套达标"变成"双套达标 + 运行时验证"。

### 维度 5 · 动效设计（9.0）

| 检查项 | 实测 |
|---|---|
| `transition: all` | **0 处**（grep 的 1 处命中为注释文字） |
| 缓动 | 统一 `--ease-out: cubic-bezier(.2,.7,.3,1)` |
| 时长分层 | 150ms 微交互 / 220ms 常规 / 400ms 位移 / 700ms 入场 |
| 入场体系 | 13 区块 + 首页 4 类元素，错峰 60ms，上限 6 档 |
| 无障碍 | `prefers-reduced-motion` 3 处，直接不启用而非缩短 |
| 合成层 | `will-change` 仅对 5 类 hover 卡片声明 |

**扣分点**：缺少更高阶编排——无视差、无数字滚动、无页面转场。这是 9.0 而非 9.5 的原因。

### 维度 6 · 微交互（9.0）

| 状态 | 覆盖数 | 说明 |
|---|---|---|
| `:hover` | 55 | — |
| `:active` | 19 | `scale(.97)` 物理按压感 |
| `:focus-visible` | 11 | 含目录条（横滚容器内需单独 outline） |
| `:disabled` | 7 | opacity .5 + not-allowed |
| tap-highlight | 已处理 | `-webkit-tap-highlight-color: transparent` |

**扣分点**：表单校验的实时反馈较弱，`:invalid` 仅在提交后触发。

### 维度 7 · 响应式（9.3）

| 检查项 | 实测 |
|---|---|
| 断点 | 6 档（1440 / 1024 / 960 / 768 / 720 / 480 / 414 / 375） |
| 横向溢出 | 7 档 × 亮暗 = 14 组，**全 0** |
| 触摸目标 | 移动端 <48px 元素 **0 个**；目录项 48px |
| 跨浏览器 | Chromium 14/14、Firefox 14/14 零溢出零报错 |
| 长页适配 | 目录条横滚，不占侧边空间 |

**扣分点**：Safari 未实测（Windows 环境限制），WebKit 引擎因 HTTP→HTTPS 强制升级无法加载本地站点。

### 维度 8 · 原创性（9.0）

| 检查项 | 证据 |
|---|---|
| 设计推导 | `DESIGN.md` 每条规范写明「为什么是这个值」 |
| 自有元素 | 印章式 brand-mark（旋转 -3°）、Hero 纸纤维纹理、栏目覆盖线、live-dot、4 种海报风格 |
| 无框架 | 未使用任何 UI 框架或模板 |
| 暗色推导 | 同色轴延展而非反转，这是可验证的设计决策 |

**扣分点**：Hero 区右侧插画在 1920 下偏小且与文字呼应不足，缺少"一眼记住"的视觉锚点。

**结论**：Design 与 Usability 已达获奖作品区间；Creativity 是最短板（9.00），主要缺"惊喜感"。
